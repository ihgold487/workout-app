# Symmetric blue native icon baseline

This directory preserves the accepted native-app icon geometry and original blue accent palette from September 1, 2026.

- `native-icon-blue-baseline-source.png`: full-resolution accepted source
- `native-icon-blue-baseline-1024.png`: native app and launch-icon rollback asset
- `native-icon-blue-baseline-192.png`: rest-timer widget rollback asset

The PWA icon is intentionally unchanged. The active native-app test variant shifts only the blue accents toward teal-green and is stored in `docs/app-icon-variants/`.
